# Projeto Android — Super Enfermagem (APK)

Esta pasta contém o projeto nativo Android (`WebView` offline em tela cheia paisagem, sem precisar de navegador externo) com ícone adaptativo da Enfermagem.

## Por que o `.apk` ainda não foi compilado neste PC?
Para gerar o arquivo `.apk` instalável, é necessário ter **Java JDK 17 + Android SDK** (ou **Android Studio**) instalados — que ainda não estão presentes nesta máquina.

## Como gerar o `.apk` (SuperEnfermagem.apk):
1. Instale o **Android Studio** (gratuito no Windows) e abra a pasta `android-app`.
2. Aguarde o Gradle sincronizar.
3. No menu superior, clique em **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. O arquivo `app-debug.apk` será gerado em `android-app\app\build\outputs\apk\debug\app-debug.apk`.
5. Você pode enviar esse `.apk` diretamente pelo **WhatsApp** para qualquer celular Android e tocar nele para instalar!
